# LG Project Docs

本目录是 `.project-governance/` 以外产品原生文档的唯一默认位置。文档先按 RequirementID 分类，再按文档类型分类；身份不明的文档进入 `_intake/unclassified/`。

完整规则见 Skill 的 `references/project-document-layout.md`。

## 标准文档类型

`discovery`、`prd`、`requirements`、`design`、`ui-previews`、`decisions`、`verification`、`release`、`references`。

## 实际内容与自定义类型

<!-- LG-MANAGED:START -->
- `_intake/`：0 个待分类文件
- `_archive/legacy-migrations/`：0 次迁移归档

新增非标准文档类型时，先创建明确命名的类型目录，再刷新本清单和对应 Requirement README。标记外内容可由项目维护者补充。
