## 唯一规范根目录

从 Skill 源码目录和当前工作目录开始逐级向上查找以下两个标记文件：

- `01_治理基线/Vibe_Coding_受控产物目录与状态模型_V6.2.md`
- `05_记录与登记册/V6.2_跨规范产物归属索引.md`

先用 `rg` 定位“适用范围”“触发条件”“Task Profile 驱动”“阻断条件”“模板骨架”和“检查清单”，再读取命中的完整章节。不要为一个小任务一次性加载 17 份全文。

每次路由记录规范文件相对路径、文档版本、Git commit 和所读章节。若文件状态为 Candidate、In Review 或 Proposed，在输出中保留该状态，不得改写为 Approved。
