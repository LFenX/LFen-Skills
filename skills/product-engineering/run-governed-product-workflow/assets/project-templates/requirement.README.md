# Requirement {{REQUIREMENT_ID}}

本目录保存 `{{REQUIREMENT_ID}}` 的产品原生文档。文件必须进入明确的文档类型目录，禁止直接散放在本层。

## 标准目录

- `discovery/`：用户、问题和机会证据。
- `prd/`：PRD 与 Feature 定义。
- `requirements/`：需求、澄清和演进说明。
- `design/`：UX、技术和架构设计。
- `ui-previews/`：评审用 HTML/PNG/JPG/WebP/SVG。
- `decisions/`：ADR 及产品/设计决定。
- `verification/`：测试、验收和验证证据。
- `release/`：发布、迁移和回滚说明。
- `references/`：外部资料与兼容输入。
